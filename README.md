# RestroCloud — منصة متعددة المطاعم

RestroCloud منصة مركزية لإدارة عدة مطاعم، مع موقع زبائن ولوحة إدارة مستقلين لكل مطعم، وبيانات معزولة عبر Supabase Row Level Security (RLS).

## لوحة الإدارة المركزية
- `platform.html`: تسجيل دخول مدير المنصة، عرض المطاعم، إنشاء مطعم جديد، وتغيير حالة المطعم.
- الرابط على GitHub Pages: `https://mohammad1194629.github.io/RestroCloud/platform.html`

## مواقع المطاعم ولوحاتها
يستخدم الإصدار الحالي قالب واجهة مشتركاً مع إعدادات وبيانات مستقلة لكل مطعم. لكل مطعم مسار مستقل للزبائن، مع لوحة إدارة منفصلة بالوصول إلى slug الخاص به:
- واجهة الزبائن: `restaurants/restaurant-slug/`
- لوحة المطعم: `admin.html?r=restaurant-slug`

المطاعم المسجلة:
- مطعم مندي ريف اليمني — `restaurants/mandi-reef-yemeni/`
- مطعم الباشا — `restaurants/al-basha/`
- مطعم الأسماك البزي — `restaurants/al-bazzi-fish/`
- Papatya Cafe — `restaurants/papatya-cafe/`
- دار النكهة — `restaurants/dar-alnakha/`
- مطعم القلعة تلعفر — `al-qalaa-talafar` (تم الحفاظ على سجل المطعم السابق).

## ملفات الواجهة
- `index.html` و `app.js`: واجهة الزبائن متعددة المستأجرين.
- `admin.html` و `admin.js`: لوحة إدارة المطعم، محددة بواسطة slug.
- `platform.html` و `platform.js` و `platform.css`: لوحة الإدارة المركزية.
- `styles.css`: تنسيق واجهة المطعم.

## قاعدة البيانات والأمان
- Supabase project: `RestaurantRestrocloud` (Frankfurt / `eu-central-1`).
- كل مطعم له UUID مستقل، وعضويات منفصلة، وإعدادات وأقسام ومنتجات وطلبات وطاولات وخدمات.
- سياسات RLS تفصل بيانات المطاعم. دالة `submit_restaurant_order` تتحقق من حالة المطعم والطاولات والمنتجات والأسعار على الخادم.
- دور مدير المنصة محفوظ في `app_metadata.role = platform_owner`، ولا يعتمد على بيانات قابلة للتعديل من المستخدم.
- مفتاح Supabase الظاهر في الواجهة هو publishable key فقط. لا تضع service_role أو secret في المتصفح.

## حالة التنفيذ والقيود الحالية
- المطاعم الخمسة الجديدة أُنشئت كمسودات، مع إعدادات أولية وعضوية مالك لحساب الإدارة المركزي.
- مطعم القلعة تلعفر بقي كما هو ونشط.
- يجب تسجيل الخروج ثم الدخول مجدداً بعد تحديث صلاحية مدير المنصة حتى يتجدد JWT.
- المطاعم الجديدة لن تظهر للعامة قبل تغيير حالتها إلى active وإضافة محتواها الحقيقي.
- الروابط الحالية مسارات داخل موقع GitHub Pages نفسه؛ أسماء النطاقات الخاصة لكل مطعم وربطها DNS لم تُضبط بعد.
- لم تُضف بعد قوائم الطعام والصور وأرقام الهواتف والعناوين الحقيقية للمطاعم.
- يجب اختبار تسجيل الدخول والطلبات وخدمات الطاولة لكل مطعم قبل الاستخدام التجاري.
