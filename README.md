# مطعم القلعة تلعفر

موقع منيو مطعم واحد، مرتبط بمشروع Supabase الخاص بـ RestroCloud.

## الملفات
- `index.html`: واجهة الزبائن.
- `admin.html`: لوحة إدارة المطعم.
- `styles.css`: تصميم متجاوب RTL.
- `app.js`: تحميل الأقسام والمنتجات وسلة الواجهة.
- `admin.js`: تسجيل دخول الإدارة وإدارة المنتجات.

## إعداد Supabase
تم إعداد رابط المشروع ومفتاح النشر العام داخل ملفات JavaScript. مفتاح النشر العام مخصص للمتصفح، أما مفاتيح `service_role` أو `secret` فلا توضع هنا مطلقاً.

معرّف المطعم المستخدم: `9c9143d1-27cf-41ac-ad6b-cc67ca08dd69`

## ملاحظات قبل الإطلاق
- حالة المطعم في قاعدة البيانات حالياً `draft`؛ لذلك لن يظهر المنيو للعامة حتى تفعيل المطعم بعد الاختبار.
- لا يوجد حتى الآن مسار آمن لإنشاء طلبات الزبائن المجهولين. لا تضف سياسة INSERT عامة إلى جدول الطلبات. يجب تجهيز RPC أو Edge Function تتحقق من الأسعار والطاولات والمنتجات على الخادم قبل فتح الطلبات.
- لم تتم إضافة رقم واتساب أو بيانات اتصال غير مؤكدة.
- استخدم HTTPS عند النشر.
